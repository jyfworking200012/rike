# 《小镇》v5.0 定版设计稿

> 定版 = 收口，不开新机制。这一版要回答的问题是：**「这游戏可以交付给一年后的自己玩了吗」**。

---

## 一、定版判断

v4.7 的核心循环已经完整且全链条验证过（打卡→招人→资源→官府三级→事件→记仇→离线衰减，47 项断言全过）。
定版只做**看得见但不改平衡**的小修，让新玩家进门不懵、老玩家到顶有交代、仓库门面说得清现状。

## 二、定版清单（6 条，全部可单独砍）

| # | 项 | 现状 | 定版改法 | rationale |
|---|---|---|---|---|
| 1 | 版本号 | APP_VER `v4.7` | `v5.0` | 封版标记。存档 `ver` 字段只做展示，`load()` 只认 `v===4`，老档兼容零风险 |
| 2 | 首夜引导 | 第 1 天空镇只有 7 张任务卡，「勾→过夜→人来」这条最核心的规则全靠猜 | 第 1 天且镇里没人时，任务区上方加一张引导卡：**「勾上今天做到的事，点过夜——今夜会有人来投奔。」**过完第一夜永久消失 | 新玩家唯一必经的懵逼点。一行字解决，不加教程层、不加弹窗 |
| 3 | 镇子建成时刻 | 16 人升「重镇」时，进度条里一句小字划过去，没有任何反馈 | 首次升到重镇：镇志（log）记一笔「重镇落成」+ toast 一句 | 定版要有「到了」的一刻。一次性触发，不是成就系统，不引入新 UI |
| 4 | README | 版本史停在 v4.7；文件表还写 selftest4（早已被 selftest5 取代） | 补 v5.0 行；文件表更新为 selftest5（145 项）+ _sim_chain.cjs（全链条 47 项） | 仓库门面。一年后打开仓库的人靠它理解现状 |
| 5 | 自检口径 | selftest5 标题写「v4.7 自检」 | 标题与注释改 v5.0，**断言一律不动** | 口径一致。145 项断言是验证过的现状，定版不许顺手改断言 |
| 6 | 缓存版本 | sw.js `town-v9` | `town-v10` | 发版纪律：改 index.html 必 bump |

## 三、砍掉不做的（定版边界，留 v5.1+）

- 新事件 / 新建筑 / 新人物 —— 任何新内容都要重新全链条验证，收益配不上定版前的风险
- 成就系统 / 结局动画 / 镇子建成大结算画面 —— #3 的一笔镇志 + toast 已经把「到了」交代了，做大了就是新系统
- AI 参谋增强 —— 默认关着，不动
- 数值调平 —— 现有数值有 rationale 且全链条跑过，定版阶段动数字 = 重新验证 145+47 项

## 四、验收口径（定版怎么算过）

1. selftest5 145 项全过 + _sim_chain.cjs 47 项全过（有新增引导卡，允许断言数 +1~2）
2. 新档第一眼能看到引导卡，过一夜后消失
3. 16 人重镇触发一次镇志 + toast
4. 线上确认 APP_VER v5.0、CACHE town-v10
5. 老存档打开不报错、不丢数据（v===4 兼容路径不变）
