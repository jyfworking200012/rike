# 《小镇》设计稿

> 这份是给你看的，不是给程序员看的。看完你只要回答一个问题：**这东西你想不想每天打开一次。**

---

## 一、一句话

**你早上做的七件小事，会变成七个活人。这七个人撑起一座镇，镇子越大，麻烦越大。**

不是"打卡攒积分换奖励"。是：**你不做，那个人就不来；他来了，镇子才长得出下一块砖。**

## 二、每天三分钟，具体发生什么

### 早上打开

```
┌─────────────────────────────┐
│ 第 12 天          5 / 6 人   │
│ 木 8  石 3  肉 4  布 2 ...   │
├─────────────────────────────┤
│      [小镇画面]              │
│   房子 / 人 / 火堆 / 炊烟     │
│   小村 · 再招 1 人升集镇      │
├─────────────────────────────┤
│ ☑ 早起    樵夫·老陈 今夜会来  │
│ ☐ 运动    猎人·阿岩           │
│ ☐ 洗澡    洗衣妇·苏姐         │
│ ☐ 学习    石匠·白先生         │
│ ☐ 不刷手机 铁匠·锤子 (需铁匠铺)│
│ ☐ 阅读    账房·纸生 (需集市)  │
│ ☐ 早睡    守夜人·灯           │
├─────────────────────────────┤
│      [ 过 夜 ]              │
│   5 人吃饭，耗 3 肉          │
└─────────────────────────────┘
```

**你做的事**：点几下（做了哪几件点哪几件），然后点「过夜」。

不需要算账。数字在上面，你只要决定"今天点几个"。

### 点了「过夜」之后

弹出来一页结算：

```
第 11 夜
老陈、阿岩 到了镇上 · 现 5 人 · 小村

老陈  砍柴        木 +5
阿岩  打猎        肉 +2
苏姐  织布        布 +2
吃饭（5 人）      − 3 肉

——这时候，一件意外发生了——

山上下来的东西
半夜，狗不叫了。栅栏外面有东西在喘。

[让阿岩去赶]        肉 1
[把门堵死，等天亮]   木 3
[不管它]            会丢两块肉
```

**三个选项，代价都写在按钮上。** 没有隐藏惩罚，也没有"标准答案"。

选完，天亮。回首页，镇子变了一点。

## 三、你为什么想回来（三个钩子）

**钩子一：人是不一样的**

七个人不是一个数字，是七个有名字、有一句话的人。

| 打卡 | 人 | 一句话 |
|---|---|---|
| 早起 | 老陈 · 樵夫 | 天不亮就上山，回来时背比门框还宽 |
| 运动 | 阿岩 · 猎人 | 腿上有旧伤，走山路比谁都快 |
| 洗澡 | 苏姐 · 洗衣妇 | 手泡得发白，全镇的布都归她管 |
| 学习 | 白先生 · 石匠 | 敲石头前先量三遍，说石头不会骗人 |
| 不刷手机 | 锤子 · 铁匠 | 话少。一开口就是要炭 |
| 阅读 | 纸生 · 账房 | 算盘打得极好，算自己那份总慢半拍 |
| 早睡 | 灯 · 守夜人 | 白天睡觉，夜里绕镇子走七圈 |

你漏了"洗澡"三天，苏姐就不在。不是扣分，是**她不在了**。

**钩子二：镇子会变**

不是数字变大。是**画面真的会长东西**。

- 第 1 天：一间破屋，屋角漏风
- 建第一个木棚：多一间房，门口多两个不认识的人
- 建井：画面里多一口井
- 建祠堂：镇子中间多一座带檐的房子
- 人多到 10 个：山脚下会多出一排远处的屋顶

**钩子三：麻烦会跟着变大**

人越多，出事越频繁，事也越大。

- 3 个人：野狗、下雨、路过的小贩
- 6 个人：疫病、塌方、夜盗
- 10 个人：早来的雪、山那边的镇子来要人

**这是"繁荣的代价"**：你不能只堆人不建东西，不然养不起也扛不住。

## 四、三个阶段长什么样

### 第 1 天（刚打开）

一间破屋，空地。你点"早起"，镇口出现一个半透明的人影——老陈今夜会来。

### 第 7 天（大概）

2–3 间木棚，5–6 个人，一个小村。你开始有选择：是先盖房收人，还是先做陷阱稳肉。

### 第 30 天（目标）

石屋、井、粮仓、铁匠铺、集市，10 人以上，山城。事件从"狗叫"变成"雪压屋梁"，你已经能用井和粮仓扛过去。

## 五、所有数值和理由

| 项 | 数 | 为什么是这个数 |
|---|---:|---|
| 木棚 | 木 10 | 樵夫一天 5 木 → **连续早起 3 天能盖第一间房**。这是第一周唯一必须记住的事 |
| 木棚容量 | +3 | 一次能收 3 个打卡的人，不至于打了卡白打 |
| 每人每天吃 | 0.5 肉 | 6 个人正好吃 3 肉 = 猎人 2 + 陷阱 1。**刚好打平**，逼你在"再收人"和"加陷阱"之间选 |
| 住不下的人 | 留 1 木走 | 不让你觉得白干，同时提示"该盖房了" |
| 事件概率 | 35% + 人口×4% | 3 人时约 47%，10 人时 75%。人越多越不安生 |
| 镇子等级 | 0 / 1 / 3 / 6 / 10 / 16 人 | 破屋 → 荒村 → 小村 → 集镇 → 山城 → 重镇 |

全部标 [待验证]：这些数是纸面推的，你玩三天我就知道对不对。

## 六、我认为最可能不好玩的地方

**这是我最想让你先判断的。**

1. **"过夜"可能变成机械动作**：点完七个格子，点过夜，看结算。三天之后你可能就不看结算了。
2. **事件没有长期后果**：选了"堵门"，明天就该没事了。没有"这个决定三个月后反咬你一口"的东西。
3. **七件全做完没有额外回报**：做 3 件和做 7 件，只是多几个人、多几个资源。少了"今天拼一把"的理由。
4. **无名居民是白来的**：建房子自动搬来 2 户，你没做什么，人就有了。可能显得不真实。

## 七、需要你拍板的三件事

**① 打卡项对不对**
现在这七件：早起 / 运动 / 洗澡 / 学习 / 不刷手机 / 阅读 / 早睡。
有哪几件是你根本不会做的？有哪件你天天做但不在里面？改这个成本最低、收益最大。

**② 你想要"慢火"还是"快爽"**
- 慢火：一天长一点，30 天建成一座镇（现在这样）
- 快爽：第一天就能建两间房，一周就有 10 个人，但 30 天后可能就没东西可建了

**③ 事件要不要"记仇"**
现在事件是一次性的。要不要做成"你今天怎么选，会影响后面"？
（例：这次把流民赶走了，十天后他带着一群人回来）
