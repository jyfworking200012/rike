# 小镇

> 你早上做的那几件小事，会变成几个人；那几个人，撑起一座镇子。

手机端单文件游戏，加到主屏即可用。数据只存在本机。

地址：https://jyfworking200012.github.io/rike/

---

## 每天怎么玩

1. 打开，点今天做到了的事（0–7 件都行，不必勉强）
2. 点「过夜」——**做了的事会有人来投奔**
3. 处理一件可能发生的意外
4. 去「建镇」花钱盖房——**房子盖上，人就搬进来**

一天三分钟。断一天不会清零：房子在，人在，只是没长。

## 核心链条

```
早起 → 老陈(樵夫) → 木
                      ↓
                  木棚 → 住得下人 → 更多人
                      ↓
              猎人打肉 / 石匠采石 / 铁匠打铁
                      ↓
        井 · 粮仓 · 铁匠铺 · 集市 · 瞭望塔 · 祠堂
                      ↓
              能扛住更大的意外
```

## 建筑能升三级

盖好的房子不只能多盖，还能往上升。**升一级，房子大一圈、脚下多一级台阶、旁边多长出一样东西**——数台阶就知道这栋升到几级。

| 建筑 | Lv1 | Lv2 | Lv3 | 升到 Lv2 要 | 升到 Lv3 要 |
|---|---|---|---|---|---|
| 粮仓 | 耗肉 −40% | −50% | −58% | 木15 石12 | 木30 石24 铁6 |
| 井 | 免疫旱/疫 | 布 +1/天 | 布 +2/天 | 石18 | 石34 铁5 |
| 铁匠铺 | 解锁铁匠 | 铁匠 铁 +1 | 铁匠 铁 +2 | 木14 石14 铁6 | 木26 石26 铁14 钱10 |
| 集市 | 解锁账房 | 账房 钱 +1 | 账房 钱 +2 | 木18 铁8 钱12 | 木34 铁18 钱26 |
| 瞭望塔 | 事件 ×0.90 | ×0.82 | ×0.75 | 木16 石18 | 木30 石32 铁8 |
| 祠堂 | 事件 ×0.60 | ×0.52 | ×0.45 | 石24 铁10 钱16 | 石44 铁20 钱34 |

**数值依据**：每级效果 +15~20%（不是翻倍——翻倍会让 Lv3 一建完就没奔头），
升级成本按 ×1.9 递增。木棚/石屋/陷阱是**数量型**，不加等级，靠多盖。

## 人在画面上长什么样

三个部件，缺一个就读错：

| 部件 | 为什么必须有 |
|---|---|
| 扁帽檐 + 锥（草帽） | 纯锥会和房子的三角屋顶撞形，一排小人看着像一排小房子 |
| 圆身 | 人只有 13px 高，画多了必糊；一块圆读起来最省 |
| 两条腿 | 只有锥 + 圆是**蘑菇**，加了腿才读成"戴帽子的人" |

帽子单独成一组，绕帽檐中心自己轻晃 1.7 度：走路快晃、干活慢晃、站着极慢晃。
整块一起上下浮动会像被人提着走，只有帽子在晃，才像戴着它的活人。

## 画面为什么是活的

镇子分两层画，是整件事的地基：

| 层 | 什么时候重画 | 里面有什么 |
|---|---|---|
| 场景层 `#scene` | 只在建筑/昼夜/人数变了才重画 | 天、山、房子、路、火堆、风车叶、火星、旗 |
| 人物层 `#folks` | 一直不重画，每帧只改坐标 | 所有村民 |

人要是画在场景层里，每次打卡都会触发重画，刚出门就被拽回原地。分开之后：

- **打卡** → 那个人从自己站的位置走向对应的作坊，到了冒一句「老陈 · 上山」
- **过夜点了「天亮了」** → 每个干活的人走到工位，冒真实数字「+5 木」
- **人多了** → 队伍变宽、站到后排去，房子不够时人还是那几个

> 注意：打卡时飘的是「谁去哪」，**不报数字**。资源要到过夜才结算，
> 那时候写 +5 是真的；打卡时写 +5 就是骗人。

|---|---|
| `index.html` | 全部内容（HTML + CSS + JS，零依赖） |

## 更新纪律

1. 改完先跑 `node selftest5.cjs`，必须 75 项全过
2. `sw.js` 的 `CACHE` 每次改版必须 +1
3. 手机上若打开还是旧版：用 `?v=<随机数>` 绕过一次旧缓存

## 历史

- v1 代币 + 抽卡 → 打卡与奖励无因果，实测 11 天打卡率 33.8%
- v2 院子 → 门槛降到 3 件，但仍无资源链
- v3 夜行 → 引入资源链，但没做出"看得见的繁荣"
- **v4 小镇** → 打卡 = 招人，建房 = 搬来人，镇子会一天天变样
- **v4.2** → 人和场景分成两层；打卡能看见有人出门干活；风车会转、铁匠铺会冒火星
- **v4.3** → 建筑能升三级：房子变大、脚下多一级台阶、旁边多长出一样东西
- **v4.4** → 人从"图钉"改成草帽小人（扁帽檐 + 圆身 + 腿，帽子会自己晃）；洗澡的对应人从洗衣妇改成赤脚医生
