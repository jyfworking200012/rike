# 《夜行》

一个自己用的、手机上的作息打卡。

**一句话**：你白天做的七件事，决定今晚能走多远；你今晚走的路，会在明天长出东西来。

线上：https://jyfworking200012.github.io/rike/

---

## 这是什么

一个文字冒险。你住在城市里，白天照常过日子，夜里城市会变形。

你不是英雄，也活不下来。你只是一个**醒着的人**，每天晚上能提着灯出门，走一段，捡点东西回来，把安全屋修得更结实一点。走得太深就回不来，但城市会记住你走过的路。

**打卡是入口，不是任务**：早起、锻炼、洗澡、学习、戒断、阅读、早睡——这七件事直接换算成今晚的灯油、胆、线索和隐蔽。

---

## 核心循环

```
白天：打勾 → 算今晚的灯油 / 胆 / 线索
  ↓
入夜：选一个街区出发 → 每步烧一滴油 → 每个节点 2~3 个选项，代价写在明面上
  ↓
结束：主动回家（带走全部） / 灯油烧干（带一半） / 受伤三次（这一代结束）
  ↓
带回材料 → 修安全屋（书架 / 沙袋 / 地图墙 / 留声机）→ 下一次走得更远
```

---

## 设计的四条硬规矩

| 规矩 | 落地方式 |
|---|---|
| **每个选择都有代价** | 选项上直接写「油 −1 · 胆 −2」，不藏信息 |
| **失败不清零** | 角色可以死，城市、建造、材料、笔记全部保留，下一代继承 |
| **走过的路会变穷** | 街区有枯竭度，越走产量越低；换路才有新东西 |
| **不掷骰子** | 成败由资源够不够决定，随机只体现在「遇到什么」 |

---

## 七个打卡项怎么变成筹码

| 打卡 | 效果 |
|---|---|
| 早起 | 灯油 +1（时间是唯一的硬预算） |
| 锻炼 | 胆 +2 |
| 洗澡 | 隐蔽 +1（一次性护盾） |
| 学习 | 线索 +1 |
| 戒断 | 胆 +1 |
| 阅读 | 线索 +2 |
| 早睡 | **今晚油 −1，明天油 +2** |

早睡是唯一的跨日交易。它故意设计成「今晚亏一步」，因为不这样就没有取舍。

灯油公式：

```
今晚灯油 = 2 + 完成件数 + (早起 ? 1 : 0) − (早睡 ? 1 : 0) + 昨日早睡奖励(2)
```

什么都不做也有 2 滴——**门槛降到零**，这是 v1/v2 最大的错误（把反馈全挂在满勤上，而满勤从没发生过）。

## 城市

12 个街区，初始解锁家附近 4 个。点亮一个街区，才能走到它后面。

每个街区有三个变量：

- `lit` 亮度 0–3：走得多会亮，亮了就安全
- `visits` 到访次数：**同一个地方走太多次，它会开始记住你**
- `drained` 枯竭度 0–5：拿得多就变穷，但每天自然恢复一点

连续到一个街区 3 次 → 出现「痕迹」节点。6 次 → 遇到「另一个你」。

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

```bash
node selftest3.cjs
```

## 更新纪律（踩过坑）

1. **每次改 `index.html` 必须 bump `sw.js` 的 `CACHE` 版本号**，否则旧缓存不会被清。
2. **HTML 入口永远不能 cache-first**。早期版本把 `index.html` 也做成 cache-first，
   结果新版本推上去、手机还显示旧页面，查了很久才发现是 SW 把入口锁死了。
   现在 HTML 走 network-first，只有断网才回退缓存。
3. iOS 主屏 PWA 几乎不会真正退出，页面不会自己刷新。`index.html` 里的
   `registerSW()` 会在启动、回到前台、每小时各检查一次更新，新 SW 接管后自动 reload 一次。

## 历史

- **v1**：打卡 → 代币 → 肉鸽 → 积分 → 兑换。11 天后实测失败（打卡率 33.8%，满勤 0 次，游戏只在头两天开过）。
- **v2**：换成「种院子」，打卡直接让院子里的东西长一寸。画面有因果了，但玩法太轻，缺少决策。
- **v3**：换成夜行。借 A Dark Room 的资源链结构——打卡产出筹码，筹码决定今晚能走多远，
  走的路改变城市，城市决定明天你能做什么。
