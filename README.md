# 小镇

> 你早上做的那几件小事，会变成几个人；那几个人，撑起一座镇子。

手机端单文件游戏，加到主屏即可用。数据只存在本机。

地址：https://jyfworking200012.github.io/rike/

---

## 每天怎么玩

1. 打开，点今天做到了的事（0–7 件都行，不必勉强）
2. 点「过夜」——**做了的事会有人来投奔**
3. 处理一件可能发生的意外
4. 去「建镇」花钱盖房——**房子盖上，人就搬进来**

一天三分钟。断一天不会清零：房子在，人在，只是没长。

## 核心链条

```
早起 → 老陈(樵夫) → 木
                      ↓
                  木棚 → 住得下人 → 更多人
                      ↓
              猎人打肉 / 石匠采石 / 铁匠打铁
                      ↓
        井 · 粮仓 · 铁匠铺 · 集市 · 瞭望塔 · 祠堂
                      ↓
              能扛住更大的意外
```

## 画面为什么是活的

镇子分两层画，是整件事的地基：

| 层 | 什么时候重画 | 里面有什么 |
|---|---|---|
| 场景层 `#scene` | 只在建筑/昼夜/人数变了才重画 | 天、山、房子、路、火堆、风车叶、火星、旗 |
| 人物层 `#folks` | 一直不重画，每帧只改坐标 | 所有村民 |

人要是画在场景层里，每次打卡都会触发重画，刚出门就被拽回原地。分开之后：

- **打卡** → 那个人从自己站的位置走向对应的作坊，到了冒一句「老陈 · 上山」
- **过夜点了「天亮了」** → 每个干活的人走到工位，冒真实数字「+5 木」
- **人多了** → 队伍变宽、站到后排去，房子不够时人还是那几个

> 注意：打卡时飘的是「谁去哪」，**不报数字**。资源要到过夜才结算，
> 那时候写 +5 是真的；打卡时写 +5 就是骗人。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 全部内容（HTML + CSS + JS，零依赖） |
| `sw.js` | 离线缓存。**HTML 走 network-first**，改版后会自动更新 |
| `manifest.webmanifest` | 加到主屏用的配置 |
| `icon.svg` | 图标 |
| `selftest5.cjs` | v4.2 自检 52 项（含人物层 / 派工状态机），`node selftest5.cjs` |
| `selftest4.cjs` | v4.0 自检 72 项，历史留存 |
| `docs/GDD-v4.md` | 设计文档（数值 rationale、失败信号） |
| `docs/shots/v42/` | 动效验证截图（空镇 / 小村 / 重镇 / 夜间 / 飘字） |

## 更新纪律

1. 改完先跑 `node selftest5.cjs`，必须 52 项全过
2. `sw.js` 的 `CACHE` 每次改版必须 +1
3. 手机上若打开还是旧版：用 `?v=<随机数>` 绕过一次旧缓存

## 历史

- v1 代币 + 抽卡 → 打卡与奖励无因果，实测 11 天打卡率 33.8%
- v2 院子 → 门槛降到 3 件，但仍无资源链
- v3 夜行 → 引入资源链，但没做出"看得见的繁荣"
- **v4 小镇** → 打卡 = 招人，建房 = 搬来人，镇子会一天天变样
- **v4.2** → 人和场景分成两层；打卡能看见有人出门干活；风车会转、铁匠铺会冒火星
